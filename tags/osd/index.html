WDS Is Being Deprecated. Microsoft's Advice? Use Configuration Manager.

Microsoft announced that Windows Deployment Services (WDS) is deprecated starting with the next Windows Server release. It keeps working on Windows Server 2025 and earlier under their normal lifecycles, but active development is done and the role is headed for removal. So what does Microsoft tell you to use instead? Not Autopilot. Not Intune. Microsoft Configuration Manager, which the notice describes as a better, more flexible and more feature-rich way to deploy Windows images. ...
