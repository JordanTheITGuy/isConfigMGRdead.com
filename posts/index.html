    Configuration Manager 2609 Release

    A new build of Configuration Manager is out: version 2609 (site version 5.00.9152.1000). Type: Current branch update, released to the early update ring on September 28, 2026. You opt in with the EnableEarlyUpdateRing2609 script until it goes generally available. What’s in it: Security hardening and fixes rather than shiny new features. SQL Server 2016 is no longer supported (SQL 2017 CU2+ is the new minimum), the site database no longer needs TRUSTWORTHY for ConfigMgr’s SQLCLR assemblies, and CMG scale sets move to new VM sizes.     ODBC Driver 18.7.1.1 Breaks Site Server SQL Connectivity

    Here’s a fun one. When an update to the Microsoft ODBC Driver 18 for SQL Server (18.7.1.1) lands on a site server, Configuration Manager can lose its connection to the site database. What it looks like sitecomp.exe crashes (exception c0000005), with COM+ errors (Event ID 4786) referencing msodbcsql18.dll in the Application log. SMSEXEC.log fills with repeated failures to connect to SQL, and hman.log threads go quiet. Why it happens According to a Microsoft response in the thread, ConfigMgr ships its own older Visual C++ runtime in its install folder, and the new ODBC driver doesn’t get along with it.
